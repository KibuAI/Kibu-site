현직 교사가 무료로 배포하는 프로그램이라 첫 다운로드 시 브라우저나 Windows 확인 창이 뜰 수 있습니다.

1단계 · 브라우저 다운로드 창
Edge: 파일 오른쪽 […] 클릭 → [유지] → [자세히 표시] → [그래도 계속]
Chrome: 다운로드 목록(Ctrl+J)에서 [계속] 또는 [위험한 파일 다운로드]
2단계 · 파란색 'Windows의 PC 보호' 창
창 가운데 작은 글씨 [추가 정보]를 누르면 오른쪽 아래에 [실행] 버튼이 나타납니다. [실행]을 누르면 바로 설치됩니다.
더 쉬운 방법: 학교 브라우저에서 .exe 다운로드가 번거로우시면 오른쪽 [압축파일로 받기 (.zip)]로 받아 압축만 풀고 Kibu.exe를 실행하세요. 한 번만 실행해 두면 다음 업데이트부터는 보안 경고 없이 앱 안에서 원클릭으로 업데이트됩니다.
  • 앱을 켜면 새 버전이 자동으로 안내되며, 상단 [도구 → 최신 버전(업데이트) 확인] 버튼으로도 언제든 즉시 업데이트됩니다.
  • 선생님 본인의 OpenAI 또는 Gemini API 키 중 하나만 있어도 모든 기능을 바로 쓰실 수 있습니다.
  • 실행에 필요한 .NET 9 데스크톱 런타임은 설치 과정에서 자동으로 확인·설치됩니다.
