Core Features

학기말 선생님의 가장 번거로운 일부터 줄여줍니다

손글씨도 있는 그대로 읽고, 나란히 대조합니다

흐린 연필·샤프 손글씨도 선명하게 보정해 글자 그대로 먼저 읽어냅니다. 빈칸으로 낸 문항을 그럴듯하게 지어내지 않으며, 잘못 읽힌 단어 하나만 고치면 처음부터 다시 기다릴 필요 없이 10초 만에 초안만 새로 써 줍니다.

모든 과목에 통하는 5가지 방향

어떤 과목이나 창체·행발이든 5가지 핵심 방향 버튼과 '한 줄 요청'만으로 선생님이 원하시는 강조점이 바로 반영됩니다.

키 하나만 넣으면 알아서 연결

OpenAI 키든 Gemini 키든 가지고 계신 키 하나만 넣으세요. 모델 이름을 몰라도 가장 알맞은 조합으로 자동 세팅됩니다.

금지어·바이트·유사 문장 점검

나이스 바이트(한글 3B)와 기재 금지어는 물론, 같은 반 학생끼리 문장이 너무 비슷하지 않은지까지 한 번에 살펴줍니다.

내 PC에만 남는 안전한 구조

Why KIBU

선생님의 학기말 풍경이 이렇게 바뀝니다

혼자 일일이 정리할 때

  • 종이 활동지 묶음과 한글·PPT 과제를 한 명씩 열어 읽고 타이핑
  • 흐린 손글씨를 잘못 읽거나 앞뒤 학생 활동지가 섞일까 늘 긴장
  • 나이스 바이트(1,500B / 900B) 계산하며 문장을 계속 줄였다 늘렸다 반복
  • 교외상·어학시험·과장 표현 같은 금지어를 눈으로 하나씩 대조
  • 여러 반 수업을 맡으면 같은 안내 작업을 반마다 처음부터 반복

KIBU AI와 함께할 때

  • 묶음 PDF도, 학생별 한글·PPT 파일도 학생 보관함으로 자동 분류
  • [스캔·추출 비교] 탭에서 원본 종이와 읽힌 글자를 나란히 보며 안심 확인
  • 한 번 읽은 활동지는 저장되어 방향을 바꿔 다시 써도 추가 판독 요금 0원
  • 금지어·바이트·학급 내 비슷한 표현까지 신호등 배지로 한눈에 점검
  • [엑셀 내보내기] 한 번에 나이스 붙여넣기용 표로 깔끔하게 완성
How it works

딱 4단계면 한 반 기록이 정리됩니다

1. 명렬표 또는 활동지 넣기
2. 손글씨·문서 자동 읽기
3. 원하는 방향 고르고 초안 생성
4. 검토 후 나이스용 엑셀 저장
Why not just a chatbot

일반 인터넷 챗봇에 올려 쓰는 것과 무엇이 다른가요?

웹 챗봇(ChatGPT·Gemini 등)에 학생 활동지를 하나씩 올리는 방식은 손이 많이 갈 뿐 아니라 개인정보와 사실 확인에서 늘 불안합니다.
KIBU는 학교 현장의 실제 생기부 마감 흐름에 맞춰 처음부터 다르게 만들었습니다.

인터넷 챗봇에 직접 올릴 때

  • 흐린 글씨나 빈칸 문항을 문맥으로 그럴듯하게 지어낼 위험
  • 단어 하나만 고쳐 달라고 해도 멀쩡하던 문장 전체가 매번 바뀜
  • 60쪽 묶음 PDF를 일일이 쪼개 올리다 다른 학생 내용과 섞이기 쉬움
  • 학생 이름·학번·연락처가 그대로 대화창에 남고 바이트 계산도 부정확

KIBU AI로 작성할 때

  • 글자 읽기와 문장 쓰기를 분리해 백지·빈칸 문항 창작을 원천 차단
  • 오독된 단어만 콕 집어 고치고 10초 만에 초안만 다시 생성
  • 30명을 한꺼번에 돌려도 학생별 공간이 완전히 분리되어 혼입 걱정 끝
  • 이름·연락처는 전송 전 가려지고, 30명 한 반 전체 비용도 약 1,000~3,500원 수준

확인된 사실만으로

학생이 실제로 제출한 글과 활동 안에서만 서술하며, 백지 활동지는 초안을 만들지 않고 바로 알려줍니다.

개인정보 자동 가림

학생 본인과 친구들의 실명·학번·전화번호가 생기부 본문이나 외부 전송에 그대로 노출되지 않게 걸러줍니다.

학교 노트북에 딱 맞게

작은 교무실 노트북 화면에서도 창이나 버튼이 잘리지 않고 학생 목록·초안·검토 카드를 한눈에 볼 수 있습니다.

최종 결정은 선생님

AI는 초안을 도와줄 뿐, 원본 활동지와 나란히 대조하고 확정하는 주체는 언제나 선생님입니다.

이 설계 원칙은 국가 개인정보·AI 보안 가이드라인 및 교원 AI·디지털 교육 역량체계와 맞닿아 있습니다.

Windows용 설치 파일 다운로드 쉬운 사용 설명서
다운로드가 차단되거나 "Windows의 PC 보호" 창이 뜨나요?

별도의 상업용 서명 인증서가 없는 설치 파일이라 처음 실행할 때 브라우저나 Windows에서 확인 창이 뜰 수 있습니다. 안전한 프로그램이니 아래 순서대로 눌러 진행해 주세요.

  • Edge 브라우저: 다운로드 목록(Ctrl+J)에서 파일 오른쪽 … → 유지 → 자세히 표시 → 그래도 계속
  • Chrome 브라우저: 다운로드 목록(Ctrl+J)에서 계속 또는 위험한 파일 다운로드
  • 파란색 "Windows의 PC 보호" 창: 추가 정보 클릭 → 오른쪽 아래 실행 클릭
  • 학교 PC 보안 차단 시: 정보 담당 선생님께 예외 허용을 요청하시거나, 개인 노트북에서 작업하실 수 있습니다.

사용 중 궁금한 점이나 건의 사항은 프로그램 안의 [문의·건의] 버튼 또는 문의 폼으로 편하게 보내 주세요.

  • 한 번 설치해 두면 다음부터는 프로그램을 켤 때 새 버전이 자동으로 업데이트됩니다.
  • 선생님 본인의 OpenAI 또는 Gemini API 키 중 하나만 있어도 모든 기능을 바로 쓰실 수 있습니다.
  • 실행에 필요한 .NET 9 환경은 설치 과정에서 알아서 확인하고 함께 설치해 줍니다.
  • 사용 전 개인정보 처리 및 AI 이용 안내를 꼭 확인해 주세요.
