Privacy & Security

개인정보 처리 및 AI 이용 안내

학생 자료가 어디에 저장되고, 무엇이 AI로 전달되는지 쉽고 투명하게 설명해 드립니다.

최종 업데이트: 2026.11.13

한눈에 보는 핵심 원칙
KIBU는 선생님 컴퓨터에 설치해 쓰는 프로그램입니다. 학생 명단·원본 자료·생성된 초안은 KIBU 제작자 서버로 절대 모으지 않으며, 오직 선생님 컴퓨터에만 저장됩니다. 다만 초안을 만들 때는 선생님이 직접 입력하신 OpenAI 또는 Google(Gemini) API 키를 통해 활동 내용이 해당 AI 회사(해외 서버)로 전달되어 처리됩니다.

선생님 PC에만 보관

명렬표·활동지·초안은 선생님 컴퓨터의 프로젝트 폴더에만 저장되며, KIBU는 별도 서버를 운영하지 않습니다.

이름·연락처 자동 가림

AI로 보내기 전에 학생 이름·학번·전화번호·이메일을 자동으로 가리고, 완성된 본문에도 실명이 남지 않게 정리합니다.

내 API 키 안전 잠금

선생님 본인의 API 키로만 작동하며, 입력한 키는 윈도우 암호화 기능으로 현재 PC 계정에만 안전하게 잠겨 저장됩니다.

스캔 이미지 전송은 선택

스캔 활동지 사진은 기본적으로 전송하지 않으며, 손글씨 판독을 위해 선생님이 허용을 켠 경우에만 전송됩니다.

1. 어떤 자료가 어디에서 처리되나요?

KIBU가 다루는 자료는 내 컴퓨터에만 머무는 것과 초안을 쓰기 위해 AI 회사로 전달되는 것으로 분명하게 나뉩니다.

자료 종류저장·처리 위치쉬운 설명
명렬표, 업로드한 원본 파일, 완성된 초안 내 PC에만 저장 선생님 컴퓨터 안의 작업 폴더에만 저장됩니다. KIBU가 외부로 수집하지 않습니다.
입력한 API 키 (OpenAI / Gemini) 내 PC 암호화 보관 윈도우 계정 암호화(DPAPI)로 잠겨 저장되며, 다른 컴퓨터로 복사해도 열리지 않습니다.
초안 작성용 활동 텍스트 (이름·연락처 가림 처리됨) AI 서비스 전송 문장을 만들기 위해 선생님이 연결한 OpenAI 또는 Google 서버로 전달됩니다.
스캔 활동지 이미지 (손글씨·도표 등) 허용 시에만 전송 기본값은 꺼짐(OFF)입니다. 손글씨 스캔본을 읽으려고 허용을 켰을 때만 전송됩니다.

2. 해외 AI 서버 전달 및 무료 키 유의사항

초안을 만들거나 손글씨를 읽을 때는 선생님이 등록한 API 키에 따라 아래 회사의 AI 서버(주로 미국 소재)를 거치게 됩니다.

  • OpenAI (GPT 모델) — 유료 API 이용 시 입력된 데이터를 AI 학습에 사용하지 않는 정책이 기본 적용됩니다.
  • Google (Gemini 모델) — 유료(결제 연동) 등급과 무료 등급의 데이터 정책이 다릅니다.
Gemini 무료(Free) 키를 쓰실 때 꼭 확인해 주세요
Google Gemini의 무료 등급 키는 입력한 내용이 구글의 모델 품질 개선(학습)에 활용될 수 있고 분당 요청 횟수도 좁습니다. 학생 활동 자료를 다루실 때는 결제 수단이 연결된 유료 등급(쓴 만큼만 과금) 키나 OpenAI API 키를 쓰시는 것을 권장합니다.

3. 개인정보를 줄이기 위한 안전장치

  • 학생 본인의 이름·학번·전화번호·이메일은 AI로 보내기 전에 자동으로 자리표시자로 가립니다.
  • 모둠 활동 기록 등에 적힌 친구 이름도 '동료 학생', '모둠원'으로 다듬어 다른 학생 실명이 생기부에 섞여 들어가지 않도록 막습니다.
  • 학급 전체를 동시에 생성해도 학생마다 작업 공간이 완전히 분리되어 앞뒤 학생 자료가 섞이지 않습니다.
다만 학생이 활동지 본문 한가운데에 직접 적어 넣은 집 주소나 가족 이야기까지 100% 완벽하게 가리기는 어렵습니다. 민감한 개인 사정이 적힌 자료는 업로드 전에 한 번 살펴봐 주시면 더욱 안전합니다.

4. 컴퓨터 보관 시 챙겨주실 점

  • 모든 자료가 선생님 컴퓨터에 남으므로, 공용 컴퓨터보다는 선생님 개인 업무용 PC·노트북에서 사용하시고 윈도우 화면 잠금을 설정해 두시는 것이 좋습니다.
  • 학기가 끝나 자료를 정리하실 때는 해당 프로젝트 폴더만 지우거나 외장하드에 옮겨 보관하시면 깔끔하게 관리됩니다.

5. 학교와 선생님의 확인 역할

KIBU는 기록 업무를 거들어 드리는 보조도구이며, 최종 기록의 주체는 언제나 선생님입니다.

  • 소속 학교·교육청의 생성형 AI 활용 안내 및 개인정보 보호 지침을 함께 확인해 주세요.
  • AI가 제안한 초안은 그대로 나이스에 넣지 마시고, [스캔·추출 비교] 탭과 검토 카드로 실제 학생 활동과 맞는지 꼭 확인·다듬어 사용해 주세요.

6. 국가 가이드라인 원칙을 어떻게 담았나요?

개인정보보호위원회와 교육부의 생성형 AI 활용 안내서에서 강조하는 안전 원칙을 선생님이 일일이 신경 쓰지 않으셔도 자연스럽게 지켜지도록 프로그램 흐름에 녹였습니다.
